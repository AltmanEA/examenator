# Change Log

All notable changes to the "examenator" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.0.6] - 2026-03-11

### Добавлено
- Поддержка необязательного поля `title` в блоках и тестах конфигурации
- В интерфейсе отображается `title` вместо `name` (если указан)

### Исправлено
- Открытие задачи теперь продолжается даже при отсутствии некоторых файлов исходного кода (показывается предупреждение, а не ошибка)
- Изменено открытие задач в новом формате: теперь открываются две вкладки (исходный код и объединённая вкладка с текстом задачи и тестом), текст задачи активен

## [0.0.5] - 2026-02-10

### Добавлено
- Обновление функциональности расширения
- Улучшения в работе с тестами
- Исправление ошибок в работе провайдеров данных
- Удалены команды по редактированию учебного репозитория

## [0.0.4] - 2026-02-06

### Added
- Обновление формата config.json
