# Change Log

All notable changes to the "examenator" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.0.12] - 2026-10-13

### Удалено

- Сброс репозитория (`git reset --hard HEAD`) перед запуском теста — ресурсоёмкая операция, вызывавшая сбои в SSH-контейнерах
- Закрытие всех редакторов (`closeAllEditors`) и всех терминалов при запуске теста и открытии задачи

### Изменено

- Запуск теста теперь выполняет только необходимое: выбор задач, отображение списка и запуск таймера
- Открытие задачи ничего не закрывает — только открывает нужные файлы и терминал
- Интервал обновления таймера в строке состояния увеличен с 250 мс до 1000 мс (снижение нагрузки на удалённый extension host)

## [0.0.11] - 2026-09-04

### Исправлено

- `openTaskAndTest`: шаблон `testTemplate` из `config.json` применялся некорректно — локальная переменная затеняла параметр функции, из-за чего тестовый файл искался с расширением `.ts` вместо указанного в конфиге `.js`

## [0.0.10] - 2026-09-04

### Удалено

- Поддержка веб-версии VS Code (vscode.dev / github.dev): удалено поле `browser` из манифеста, сборка переключена с `platform: 'neutral'` на `platform: 'node'`, убраны упоминания веб-версии из документации

## [0.0.9] - 2026-09-02

### Исправлено

- Веб-версия (vscode.dev / github.dev): расширение не активировалось с ошибкой «Отсутствует зарегистрированный поставщик данных…» — web extension host не умеет загружать `require('./модуль')` отдельных файлов. Код расширения теперь бандлится esbuild в единый файл `dist/extension.js`, точки входа `main`/`browser` указывают на него

### Изменено

- Сборка расширения переведена с `tsc` на esbuild (`esbuild.config.mjs`); `tsc` используется только для компиляции тестов (`out/`)
- Новые скрипты: `npm run bundle` (dev-бандл), `npm run watch` (наблюдение), `npm run package` (production-бандл с минификацией)

## [0.0.8] - 2026-09-02

### Добавлено
- Поддержка Web Extensions: расширение можно устанавливать и запускать в vscode.dev и github.dev
- Чтение и запись `config.json` переведены на `vscode.workspace.fs` (работает и на десктопе, и в вебе)

### Изменено
- В веб-режиме терминалы и сброс репозитория (`git reset --hard HEAD`) недоступны — вместо этого показывается предупреждение «недоступно в веб-версии»
- Точка входа для веб-режима задана полем `browser` в манифесте

## [0.0.6] - 2026-03-11

### Добавлено
- Поддержка необязательного поля `title` в блоках и тестах конфигурации
- В интерфейсе отображается `title` вместо `name` (если указан)

### Исправлено
- Открытие задачи теперь продолжается даже при отсутствии некоторых файлов исходного кода (показывается предупреждение, а не ошибка)
- Изменено открытие задач в новом формате: теперь открываются две вкладки (исходный код и объединённая вкладка с текстом задачи и тестом), текст задачи активен
