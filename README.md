# Examenator - Расширение для проверки навыков программирования

Расширение для VS Code, предназначенное для организации и проведения экзаменов по программированию. Позволяет создавать блоки задач, формировать тесты с временными ограничениями и автоматически проверять решения.

## Возможности

### 🎯 Управление задачами
- **Создание блоков задач** - организуйте задачи по темам или сложности
- **Шаблоны файлов** - настраиваемые шаблоны для файлов задач и тестов
- **Автоматическая нумерация** - задачи нумеруются от 01 до 100 в каждом блоке

### ⏱️ Тестирование с временными ограничениями
- **Таймер обратного отсчета** - визуальный отсчет времени в Status Bar
- **Цветовая индикация**:
  - 🟢 Зеленый - нормальное время
  - 🟡 Желтый - осталось 30% времени  
  - 🔴 Красный - осталось 10% времени
- **Автоматическое уведомление** - предупреждение при окончании времени

### 🚀 Запуск и проверка
- **Случайный выбор задач** - автоматический выбор задач из указанных блоков
- **Одновременное открытие** - код задачи и теста открываются в соседних панелях
- **Автозапуск тестов** - автоматический запуск тестов в отдельном терминале
- **Изоляция тестов** - каждый тест запускается в новом терминале

## Быстрый старт

### 1. Установка
```bash
# Установка через VS Code
# Или клонирование репозитория
git clone https://github.com/AltmanEA/examenator.git
cd examenator
npm install
```

### 2. Создание конфигурации
1. Откройте панель "Экзаменатор" в Activity Bar
2. Нажмите "Создать конфигурацию" в разделе "Задачи"
3. В рабочей папке создастся файл `config.json`

### 3. Добавление блоков задач
1. Нажмите кнопку "+" в заголовке раздела "Задачи"
2. Введите название блока (например, "algorithms")
3. Автоматически создастся папка `src/algorithms/`

### 4. Добавление задач
1. Кликните на блок в разделе "Задачи"
2. Введите имя задачи (латинские буквы, цифры, подчеркивания)
3. Автоматически создадутся три файла:
   - `blockName_taskName.ts` - файл исходного кода задачи
   - `blockName_taskName.ts` - файл условия задачи
   - `blockName_taskName.test.ts` - файл теста
4. Файлы откроются в редакторе

### 5. Создание теста
1. Нажмите "+" в разделе "Тесты"
2. Введите время в секундах
3. Добавьте блоки задач в тест через редактирование config.json

### 6. Запуск теста
1. Кликните на тест в разделе "Тесты"
2. Автоматически:
   - Закроются все открытые редакторы и терминалы
   - Выберутся случайные задачи из указанных блоков
   - Запустится таймер
   - Задачи появятся в разделе "Активный тест"

## Конфигурация

### Структура config.json
```json
{
  "blocks": [
    {
      "name": "algorithms",
      "tasks": ["task1", "task2"],
      "templates": {
        "source": "{block}_{task}.ts",
        "task": "{block}_{task}.md",
        "test": "{block}_{task}.test.ts"
      }
    }
  ],
  "tests": [
    {
      "time": 600,
      "blocks": [
        {
          "block": "algorithms arrays",
          "task": 2
        }
      ]
    }
  ],
  "path": "src"
}
```

### Настройка шаблонов
Используйте плейсхолдеры в шаблонах:
- `{block}` - название блока
- `{task}` - имя задачи

**Примеры шаблонов:**
```json
{
  "templates": {
    "source": "src_{task}_{block}.js",
    "task": "task_{task}_{block}.md",
    "test": "test_{task}_{block}.spec.js"
  }
}
```

### Формат блоков в тестах
- `"block": "algorithms"` - задачи только из блока "algorithms"
- `"block": "algorithms arrays"` - задачи из блоков "algorithms" и "arrays"

## Использование в учебном процессе

### Для преподавателей
1. Создайте блоки задач по темам курса
2. Настройте шаблоны под используемый язык программирования
3. Создайте тесты с разным временем и комбинациями задач
4. Распределите тесты по сложности

### Для студентов
1. Запустите тест для получения набора задач
2. Решайте задачи в отведенное время
3. Используйте встроенные тесты для проверки решений
4. Следите за оставшимся временем через Status Bar

## Разработка

### Установка для разработки
```bash
git clone https://github.com/AltmanEA/examenator.git
cd examenator
npm install
npm run compile
```

### Запуск в режиме разработки
1. Нажмите F5 в VS Code
2. Откроется новое окно с расширением
3. Используйте Ctrl+Shift+P → "Developer: Reload Window" для перезагрузки

### Запуск тестов
```bash
npm test
```
