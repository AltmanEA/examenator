# План упрощения расширения (SSH-контейнер, нехватка ресурсов)

## Контекст проблемы

Расширение используется в контейнере, к которому VS Code подключается по Remote-SSH
(extension host работает внутри контейнера). Сбои происходят из-за пиковой нагрузки:

| Операция | Где | Стоимость в контейнере |
|---|---|---|
| `git reset --hard HEAD` через терминал | `runTest` | спавн шелла + git-подпроцессы, дисковый I/O, блокировка на 2 с |
| Закрытие всех терминалов (`terminals.forEach(dispose)`) | `runTest`, `openTaskAndTest` | волна уничтожения псевдотерминалов и шелл-процессов |
| Закрытие всех редакторов (`closeAllEditors`) | `runTest`, `openTaskAndTest` | шквал событий выгрузки документов с удалённой ФС |
| Таймер status bar каждые 250 мс | `ActiveTestProvider` | 4 RPC-обновления в секунду вместо необходимых 1 |

## Целевое поведение

- **Запуск теста** (`examView.runTest`): прочитать `config.json` → случайно выбрать
  задачи по блокам теста → отобразить в «Выбранные задачи» → запустить таймер.
  Ничего не сбрасывать, ничего не закрывать, лишних окон/терминалов не создавать.
- **Открытие задачи** (`examView.openTaskAndTest`): открыть нужные файлы (2 или 3
  в зависимости от формата) → показать терминал задачи (при отсутствии — создать и
  запустить тест-команду). Ничего не закрывать.

## Шаги

### 1. `src/activeTestProvider.ts` — команда `runTest`

- Удалить функцию `resetRepositoryToHead()` целиком (строки 10–27) и её вызов
  в `runTestCommand`.
- Удалить в `runTestCommand` закрытие всех терминалов
  (`vscode.window.terminals.forEach(dispose)`) и `workbench.action.closeAllEditors`.
- В команде остаются только: `readConfig()` → выбор задач по блокам (`shuffle`/
  `collectTasksFromBlock`) → `activeTestProvider.setActiveTest(...)`
  (он обновляет TreeView и запускает таймер).
- Убрать `await`/`async` там, где они стали не нужны (команда остаётся async из-за
  `readConfig`).

### 2. `src/activeTestProvider.ts` — команда `openTaskAndTest`

- Удалить `workbench.action.closeAllEditors` и закрытие всех терминалов
  (строки 183–188).
- Всё остальное сохранить: открытие файлов (старый формат — 2 файла, новый — 3),
  переиспользование терминала по имени `Тест: <name> (<block>)`, запуск
  `testCommand` (по умолчанию `npm run test`), `terminal.show()`,
  проверка `isWeb()` для терминалов остаётся.

### 3. `src/activeTestProvider.ts` — таймер

- Интервал `setInterval` в `startTimer()` увеличить с 250 мс до 1000 мс
  (отсчёт в секундах — точность отображения не страдает, нагрузка падает в 4 раза).

## Что НЕ меняем

- Форматы конфигов и типы `Block`/`Tests`/`SelectedTask` — без изменений.
- Логика случайного выбора задач, шаблоны имён файлов, форматирование status bar.
- Защита от накопления терминалов: переиспользование терминала по имени уже
  предотвращает дубли при повторном открытии той же задачи.
- `package.json`: заголовки команд (`Запустить тест`, `Открыть задачу и тест`)
  остаются прежними (кроме номера версии).
