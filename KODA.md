# KODA.md — Examenator

## Обзор проекта

**Examenator** — расширение для Visual Studio Code, предназначенное для организации и проведения структурированного тестирования (экзаменации). Расширение позволяет:

- Создавать структурированные тесты из блоков задач (`config.json` в корне рабочей области).
- Случайно выбирать задачи из блоков при запуске теста.
- Отслеживать время выполнения через таймер в строке состояния с визуальными индикаторами (зелёный → жёлтый → красный).
- Автоматически сбрасывать репозиторий к последнему коммиту (`git reset --hard HEAD`) перед началом теста.
- Открывать файлы задачи и теста в отдельных вкладках и запускать тесты в терминале.

### Технологии

- **TypeScript** (strict mode, target ES2022, module Node16), компиляция через `tsc`.
- **VS Code Extension API** (`@types/vscode` ^1.105.0, точка входа `./out/extension.js`).
- **Тестирование**: `@vscode/test-cli` + `@vscode/test-electron` (Mocha-стиль `suite`/`test`), моки через **sinon**.
- **Линтинг**: ESLint 9 (flat config, `eslint.config.mjs`).
- **Упаковка**: `vsce package`.
- Внешние зависимости: Git (для сброса репозитория), Node.js `fs/promises`.

## Структура проекта

```
├── src/
│   ├── extension.ts           # Точка входа: регистрация команд и TreeView
│   ├── config.ts              # Чтение/запись config.json, типы Block и Tests
│   ├── taskProvider.ts        # TreeView «Задачи» (список блоков)
│   ├── testProvider.ts        # TreeView «Тесты» (список тестов)
│   ├── activeTestProvider.ts  # TreeView «Выбранные задачи», таймер, команды открытия задач
│   └── test/                  # Интеграционные/юнит-тесты (Mocha + sinon)
├── config.json                # Пример конфигурации блоков и тестов
├── spec.md                    # Спецификация расширения (архитектура, поток выполнения)
├── package.json               # Манифест расширения: команды, viewsContainers, views
├── tsconfig.json              # strict TS, outDir=out, rootDir=src
├── eslint.config.mjs          # Flat config ESLint
└── .vscode-test.mjs           # Конфигурация тест-раннера (out/test/**/*.test.js)
```

### Архитектура

1. **Extension** (`src/extension.ts`) — активация, создание трёх TreeView и регистрация команд `examView.runTest`, `examView.selectBlock`.
2. **Config** (`src/config.ts`) — чтение `config.json` из корня рабочей области; при отсутствии файла создаётся конфигурация по умолчанию.
3. **Providers**:
   - `TasksProvider` — блоки задач (ручная нумерация через `tasks: string[]` или автоматическая через `task: number`).
   - `TestsProvider` — список тестов с временем и составом блоков.
   - `ActiveTestProvider` — выбранные задачи, таймер обратного отсчёта в StatusBarItem (предупреждение при 30% остатка, тревога при 10%), команда `openTaskAndTest`.
4. **Форматы файлов задач**: старый (2 файла: `template` + `testTemplate`) и новый (3 файла: `templates.source/task/test`); подстановка переменных `{block}` и `{task}` в имена файлов.

### Команды расширения (манифест)

| Команда | Назначение |
|---|---|
| `examView.runTest` | Запустить тест |
| `examView.openTest` | Открыть тестовый файл |
| `examView.openTaskAndTest` | Открыть задачу и тест |
| `examView.runTest` | Сброс репозитория, случайный выбор задач, запуск таймера (вызывается при клике на тест в интерфейсе) |
| `examView.selectBlock` (внутренняя) | Выбрать все задачи блока |

## Сборка, запуск и тестирование

```bash
npm install            # установка зависимостей

npm run compile        # компиляция TypeScript (tsc -p ./) → out/
npm run watch          # компиляция в режиме наблюдения

npm run lint           # ESLint по src/
npm test               # vscode-test (перед тестами автоматически compile + lint)
npm run build          # упаковка .vsix через vsce package
```

- Отладка в VS Code: конфигурация запуска в `.vscode/launch.json` (Extension Development Host).
- Тесты запускаются через `@vscode/test-cli`; конфигурация — `.vscode-test.mjs`, файлы тестов: `out/test/**/*.test.js`.
- Минимальная версия VS Code: **1.105.0**.

## Правила разработки

- **Язык интерфейса и сообщений**: русский — все названия команд, представления, уведомления и сообщения об ошибках пишутся на русском.
- **Комментарии в коде**: на русском языке.
- **TypeScript strict mode** включён; цель ES2022.
- **Стиль кода** (ESLint, уровень `warn`): точки с запятой обязательны (`semi`), фигурные скобки для всех ветвлений (`curly`), строгое равенство (`eqeqeq`), запрет `throw` литералов, именование импортов в camelCase/PascalCase.
- **Тесты**: Mocha-стиль (`suite`/`test`), изоляция через sinon sandbox (`setup`/`teardown`); тесты лежат в `src/test/*.test.ts` и компилируются вместе с исходниками.
- **Изменения конфигурации**: структура типов `Block`/`Tests` в `src/config.ts` — источник истины; документация конфигурации дублируется в `README.md` и `spec.md` (при изменении схемы обновлять все три места).
- **Работа с Git**: расширение выполняет `git reset --hard HEAD` в терминале пользователя — при рефакторинге этой логики соблюдать осторожность (необратимая операция).
